# Magic Pet
[Проект на GitHub](https://github.com/Pixel-Point-Studio/trial-lesson-magic-pet/)  |  [Задачи проекта](https://github.com/Pixel-Point-Studio/trial-lesson-magic-pet/issues)  
Magic Pet — Telegram-бот с искусственным интеллектом и тремя магическими питомцами:

- **Учёба** — совёнок;
- **Спорт** — дракончик;
- **Личный блог** — лисёнок.

Пользователь выбирает тему, даёт питомцу имя и пишет свою цель. Бот составляет план, выдаёт задания и начисляет опыт. Питомец повышает уровень и меняется вместе с пользователем.

### Технологии
Проект написан на языке программирования Java, для хранения данных используется SQLite.  
Среди основных интеграций проекта - Telegram и OpenAI (модель ChatGPT).


## Настройка проекта

### 1. Подключение LLM ChatGPT
1. Открой файл `.env` слева.
2. Найди строку `LLM_API_KEY=`.
3. После `=` вставь токен от ChatGPT.
4. Сохрани через **Cmd+S** на Mac или **Ctrl+S** на Windows.

### 2. Подключение Телеграм бота

Если у вас уже есть токен для Телеграм бота:

1. Открой файл `.env` слева.
2. Найди строку `TELEGRAM_BOT_TOKEN=`.
3. После `=` вставь токен от ТГ Бота.
4. Сохрани через **Cmd+S** на Mac или **Ctrl+S** на Windows.

Если у вас еще нет бота в Телеграм необходимо создать бота и получить токен:
1. В Telegram открой официальный аккаунт **@BotFather**.
2. Отправь `/newbot`.
3. BotFather попросит обычное видимое имя. Можно написать, например, `Magic Pet` — здесь допустимы русские или английские буквы.
4. Затем он попросит служебное имя бота. Оно пишется английскими буквами, должно заканчиваться на `bot` и быть уникальным, например `magic_pet_4821_bot`.
5. Если имя занято, добавь несколько случайных цифр и отправь снова.
6. BotFather пришлёт длинную строку с двоеточием — токен. Нажми на неё один раз или удерживай и выбери **Copy / Копировать**.

## Запуск проекта

1. Нажми слева **Запуск и отладка** — значок треугольника с жуком.
2. Вверху выбери **Magic Pet: запустить и отлаживать**.
3. Нажми зелёный треугольник.
4. Дождись сообщения **«Magic Pet запущен»**.
5. Открой именно своего нового бота, а не BotFather, и отправь `/start`.

После запуска зелёный треугольник превращается в красный квадрат **Stop** на панели запуска. Если его не видно, снова открой слева раздел **Запуск и отладка**.

Чтобы увидеть изменение кода:

1. Сохрани файл.
2. Нажми красный квадрат **Stop**.
3. Снова нажми зелёный треугольник **Start**.

Не используй кнопку Restart: для этого проекта надёжнее отдельные Stop и Start.

Чтобы начать путь пользователя сначала, отправь боту `/reset`, затем `/start`.

## Ключевые понятия проекта

Главный файл для разработки сценариев бота:  
[`PetFeatures.java`](src/main/java/studio/pixelpoint/magicpet/lesson/PetFeatures.java)  
Файлы в VSCode также можно открывать сочетанием клавиш **Cmd+P**, после чего нужно ввести название файла (например `PetFeatures.java`) и нажать Enter.

В этом файле:

- `pet` — объект, обозначающий питомца;
- `user` — текущий пользователь Telegram;
- `message` — сообщение или нажатая кнопка;
- `Button("скрытое имя", "видимый текст")` — создание одной кнопки;
- `buttons.add(...)` — добавить кнопку в меню;
- `handleButton(...)` — место, где программа узнаёт нажатую кнопку;
- `return true` — «кнопку уже узнали, дальше искать обработчик не нужно»;
- `//` в начале строки временно выключает эту строку; удалить `//` — включить её.
- `user.state()` — текущий шаг разговора с пользователем;
- `WAITING_PET_RENAME` — шаг «бот ждёт, что следующим сообщением человек пришлёт новое имя»;
- `pet.confirmTaskDeletion` - метод для удаления задачи с подтверждением;
- **контекстная кнопка** относится только к текущей карточке: например, «Выполнено», «Удалить» или «Да / Нет».
- `pet.beginPetRename(user)` - метод, который запускает сценарий переименования пользователя - буквально просит пользователя ввести новое имя питомца;
- `pet.showPet(user)` - метод, который показывает информацию о питомце;
- `pet.renamePet(user, message.text())` - метод, для переименование питомца

Общие кнопки меню показываются **после** кнопок текущего действия. Например, на карточке задания сначала находится «Выполнено», а ниже — «Переименовать питомца, «Показать моего питомца и остальные пункты меню.

## Проверка работы кода

Сначала проверь результат в Telegram. Затем:

1. Открой верхнее меню **Terminal → Run Task… / Терминал → Выполнить задачу…**.
2. Выбери **Magic Pet: проверить задание**.
3. Введи номер задания: `1`, `2`, `3` или `4`.

Успешный результат:

```text
✅ Задание N выполнено
```

Здесь `N` — номер, который был введён: `1`, `2`, `3` или `4`.

## Посмотреть изменения перед отправкой кода

Открой слева **Source Control / Контроль версий** (иконка ветки с 3 точками). Нажми на `PetFeatures.java`: добавленные строки будут зелёными, удалённые — красными.

## Менеджеру продукта

### Подготовить отдельную папку занятия

Одинаково на macOS, Windows и Linux:

1. Откройте исходную папку `trial-lesson-magic-pet` в Visual Studio Code.
2. Откройте верхнее меню **Terminal → Run Task… / Терминал → Выполнить задачу…**.
3. Выберите **Magic Pet: подготовить пробный урок**.
4. Дождитесь, пока Visual Studio Code откроет новое окно с готовой папкой и файлом `README.md`.

Учебный `README.md` — короткая карта открытой на экране папки: где вставить токен, как запустить бот и какой файл открыть.

Технический запасной способ для macOS и Linux для подготовки папки занятия:

```bash
./gradlew prepareLesson
```

Для Windows: `gradlew.bat prepareLesson`.

Если OpenAI временно недоступен, бот сам использует готовый резервный план. В безопасном логе появится `ai.plan_generated` при успехе или `ai.plan_fallback` при переходе на резерв.

Чтобы начать путь пользователя заново, отправьте боту `/reset`, затем `/start`.

### Проверить одну задачу

1. Откройте **Terminal → Run Task… / Терминал → Выполнить задачу…**.
2. Выберите **Magic Pet: проверить задание**.
3. Введите номер `1`, `2`, `3` или `4`.

Успешная проверка заканчивается понятным сообщением на русском. Чтобы увидеть собственные изменения, откройте раздел **Source Control / Контроль версий** в Visual Studio Code: добавленные строки будут зелёными, удалённые — красными.

### Основные команды

Основные служебные проверки менеджера:

```bash
./scripts/check-computer.sh
./scripts/test-prepare-lesson.sh
./scripts/final-acceptance.sh
```

`final-acceptance.sh` — проверка новой версии продукта перед выпуском. Менеджер не запускает её перед занятием.

Полный ручной путь проверки в правильном порядке — от слепой сессии с новичком до автоматики и документации — находится в [инструкции по готовности пробного урока](acceptance/OWNER-READINESS-GUIDE.md).

Для автоматического переноса OpenAI-настроек создайте локальный `.env.lesson-secrets` по примеру `.env.lesson-secrets.example`. Этот файл и настоящие ключи не попадают в Git. Telegram-токен намеренно добавляется отдельно для каждого урока.
