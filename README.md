# Magic Pet — walkthrough 1–2

Рабочий Telegram-бот для пробного урока Pixel Point Studio. Пользователь выбирает один из трёх путей, называет питомца, формулирует цель, получает локальный план из трёх задач и развивает питомца выполнением заданий.

## Требования

- JDK 21 или новее;
- Telegram-бот и токен от [@BotFather](https://t.me/BotFather).

Gradle отдельно устанавливать не нужно: wrapper включён в репозиторий.

## Запуск

1. Создайте локальный файл конфигурации:

   ```bash
   cp .env.example .env
   ```

2. Вставьте токен в `.env` вместо `replace_me`.
3. Запустите приложение:

   ```bash
   ./gradlew run
   ```

4. Откройте бота в Telegram и отправьте `/start`.

Если токен не задан, приложение завершится с инструкцией и не выведет секреты в консоль.

## Проверка

```bash
./gradlew test
```

Сквозной тест проходит путь от `/start` до 100 XP и уровня 2. Отдельные тесты проверяют три fallback-плана, структуру UI-текстов и будущего AI-промпта, а также защиту от повторной доставки одного callback.

## Что входит в walkthrough 1–2

- Java 21 и Gradle 9.2.1;
- TelegramBots 10.3.0, long polling;
- SQLite-хранилище с миграциями Flyway;
- восстановление состояния onboarding, плана, задач и XP после перезапуска;
- изоляция пользователей по Telegram ID и транзакционное завершение задач;
- постоянная защита от повторной доставки callback;
- независимые порты `TelegramGateway`, `UserStore`, `PlanGenerator`, `AssetCatalog`;
- три локальных плана без сетевого AI;
- 50 XP за задачу и переход на уровень 2 после второй задачи;
- русские тексты и AI-контракт в отдельных JSON-ресурсах;
- необязательные PNG: сначала ищутся `assets/<scenario>/level-<n>.png`, затем используются включённые `assets/runa-<n>.png`, а при отсутствии показывается текст.

## Известные ограничения

- план пока шаблонный и не обращается к AI;
- отдельные изображения для каждого сценария появятся в walkthrough 3;
- ручной smoke требует действующего Telegram-токена и доступа к Telegram.
