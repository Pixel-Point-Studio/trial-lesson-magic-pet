# Magic Pet

Magic Pet — Telegram-бот с искусственным интеллектом и тремя магическими питомцами:

- **Учёба** — совёнок;
- **Спорт** — дракончик;
- **Личный блог** — лисёнок.

Пользователь выбирает тему, даёт питомцу имя и пишет свою цель. Бот составляет план, выдаёт задания и начисляет опыт. Питомец повышает уровень и меняется вместе с пользователем.

На пробном уроке студент не создаёт программу с пустого экрана. Он работает как разработчик в готовом продукте: исследует бот, исправляет одну понятную ошибку, добавляет одну возможность и сразу видит результат в Telegram.

## Студенту и менеджеру

Основная пошаговая инструкция находится в [методичке пробного урока](https://www.notion.so/3e16ba2ce4e8801a9c67c1830814439b). Идите по ней сверху вниз.

В методичке сразу находятся сценарий МОПа, действия студента, объяснения, код, подсказки и проверка результата. Переходить между несколькими инструкциями не нужно.

Студент выбирает любого питомца, но задания одинаковы для всех трёх вариантов:

1. исправить сохранение придуманного имени;
2. добавить переименование питомца;
3. добавить подтверждение перед удалением задачи;
4. при наличии времени — кнопку «Показать моего питомца.

[GitHub Issues](https://github.com/Pixel-Point-Studio/trial-lesson-magic-pet/issues) остаётся страницей команды, но на уроке все необходимые формулировки уже даны в методичке.

### Подготовить отдельную папку занятия

Одинаково на macOS, Windows и Linux:

1. Откройте исходную папку `trial-lesson-magic-pet` в Visual Studio Code.
2. Откройте верхнее меню **Terminal → Run Task… / Терминал → Выполнить задачу…**.
3. Выберите **Magic Pet: подготовить пробный урок**.
4. Дождитесь, пока Visual Studio Code откроет новое окно с готовой папкой и файлом `README.md`.

Вводить имя студента и заранее выбирать тему не нужно. В новой папке доступны все три питомца и четыре общих задания.

В новом окне убедитесь, что открыт `README.md` и внизу нет надписи **Restricted Mode**. Если она есть, нажмите её, выберите **Manage → Trust** и дождитесь, пока папка перезагрузится. Только после этого передайте студенту мышь и клавиатуру.

Учебный `README.md` — короткая карта открытой на экране папки: где вставить токен, как запустить бот и какой файл открыть. Это не вторая методичка и не отдельный набор заданий. Сам сценарий, объяснения и задания находятся только в единой методичке Notion.

Технический запасной способ для macOS и Linux:

```bash
./gradlew prepareLesson
```

Для Windows: `gradlew.bat prepareLesson`.

### Подключить Telegram и запустить бот

1. Откройте файл `.env`.
2. Вставьте Telegram-токен после `TELEGRAM_BOT_TOKEN=` и сохраните файл.
3. Откройте в Visual Studio Code раздел **Запуск и отладка**.
4. Выберите **Magic Pet: запустить и отлаживать**.
5. Отправьте своему боту `/start`.

Настройки OpenAI обычно уже перенесены автоматически. Если OpenAI временно недоступен, бот сам использует готовый резервный план. В безопасном логе появится `ai.plan_generated` при успехе или `ai.plan_fallback` при переходе на резерв.

Чтобы начать путь пользователя заново, отправьте боту `/reset`, затем `/start`.

### Проверить одну задачу

1. Откройте **Terminal → Run Task… / Терминал → Выполнить задачу…**.
2. Выберите **Magic Pet: проверить задание**.
3. Введите номер `1`, `2`, `3` или `4`.

Успешная проверка заканчивается понятным сообщением на русском. Чтобы увидеть собственные изменения, откройте раздел **Source Control / Контроль версий** в Visual Studio Code: добавленные строки будут зелёными, удалённые — красными.

## Владельцу продукта

Техническая архитектура, первоначальная настройка компьютеров, OpenAI, секреты, восстановление и полная приёмка вынесены в отдельную [техническую инструкцию владельца продукта](https://www.notion.so/3e26ba2ce4e8813b9fedce0a5342f657). Эти детали не нужно объяснять менеджеру или студенту.

Основные служебные проверки владельца:

```bash
./scripts/check-computer.sh
./scripts/test-prepare-lesson.sh
./scripts/final-acceptance.sh
```

`final-acceptance.sh` — проверка новой версии продукта перед выпуском. Менеджер не запускает её перед занятием.

Полный ручной путь проверки в правильном порядке — от слепой сессии с новичком до автоматики и документации — находится в [инструкции по готовности пробного урока](acceptance/OWNER-READINESS-GUIDE.md).

Для автоматического переноса OpenAI-настроек создайте локальный `.env.lesson-secrets` по примеру `.env.lesson-secrets.example`. Этот файл и настоящие ключи не попадают в Git. Telegram-токен намеренно добавляется отдельно для каждого урока.
