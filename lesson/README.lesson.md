# Начни здесь: твоя папка Magic Pet

Эта папка уже подготовлена для занятия. Повторно запускать подготовку здесь не нужно.

Это твоя карта проекта. Сегодня компьютер находится у тебя: сам открывай файлы, запускай бота и проверяй изменения. Менеджер будет задавать вопросы и подсказывать направление, но не должен делать работу вместо тебя.

Не нужно понимать весь код. Разработчики тоже начинают с README, находят небольшой участок проекта и исследуют только то, что относится к их задаче.

## 1. Подключи Telegram-бота

1. Открой файл `.env` слева в Visual Studio Code.
2. Найди строку `TELEGRAM_BOT_TOKEN=replace_me`.
3. Замени только `replace_me` на токен от BotFather или запасного школьного бота.
4. Сохрани файл через **Cmd+S** на Mac или **Ctrl+S** на Windows.
5. Закрой `.env`, чтобы секрет не оставался на экране.

Если указан резервный план, урок всё равно можно продолжать: бот автоматически использует готовые задания.

## 2. Запусти Magic Pet

1. Нажми слева **Запуск и отладка** — значок треугольника с жуком.
2. Вверху выбери **Magic Pet: запустить и отлаживать**.
3. Нажми зелёный треугольник.
4. Дождись сообщения **«Magic Pet запущен»**.
5. Открой своего бота в Telegram и отправь `/start`.

Чтобы начать путь пользователя заново, отправь `/reset`, затем `/start`.

## 3. Исследуй продукт

Пройди начало продукта: выбери тему, дай Pet имя, напиши цель и получи план. Сравни поведение с демонстрационным ботом и попробуй заметить отличие.

## 4. Выбери задачи в GitHub

### Как эти файлы связаны

Сообщение из Telegram сначала приходит в [`StudentBot.java`](src/main/java/studio/pixelpoint/magicpet/lesson/StudentBot.java). Он передаёт работу файлу выбранной темы. Файл темы решает, какую кнопку показать и какое готовое действие вызвать. Сами готовые действия собраны в [`PetFacade.java`](src/main/java/studio/pixelpoint/magicpet/application/PetFacade.java).

В файле темы:

- `taskButtons()` возвращает дополнительные кнопки этой темы;
- `handleButton()` решает, что делать после нажатия кнопки;
- `handleText()` обрабатывает следующий текст пользователя;
- `afterTaskCompleted()` описывает, что показать после выполнения задания;
- переменная `pet` даёт доступ к готовым действиям продукта.

В `PetFacade` уже есть действия с говорящими названиями: показать Pet, подсказку или план, начать переименование, показать прогресс уровня, запросить подтверждение и удалить задачу. Запоминать их не нужно: открой файл или используй поиск **Cmd+Shift+F / Ctrl+Shift+F**. Через **Cmd+клик / Ctrl+клик** по названию метода можно посмотреть его описание и вернуться назад.

## 6. Исследуй код и внеси изменение

1. Прочитай в карточке GitHub, что происходит сейчас и как должно работать.
2. Открой файл из карточки или карты выше.
3. Найди комментарий `TODO STUDENT` с кодом своей задачи.
4. Прочитай описание класса в верхней части файла.
5. Посмотри на соседний рабочий код: часто нужная конструкция уже используется рядом.
6. Если видишь вызов `pet.чтоТоСделать(...)`, перейди к нему через **Cmd+клик / Ctrl+клик** и посмотри, что делает это действие.
7. Измени только минимально необходимое место и сохрани файл.
8. Если застрял, сначала скажи, что именно уже понял. Менеджер даст следующую подсказку.

Обычно файлы `StudentBot.java` и `PetFacade.java` нужно только читать. Не меняй их, если карточка задачи прямо об этом не просит.

## 7. Проверь результат

Сначала проверь изменение в Telegram. Затем открой **Terminal → Run Task… / Терминал → Выполнить задачу…**, выбери **Magic Pet: проверить задание** и введи код из карточки, например `S1`.

Готовая задача заканчивается сообщением **«✅ Задание выполнено»**.

## 8. Посмотри собственные изменения

Открой слева **Source Control / Контроль версий**. Нажми на изменённый файл: добавленные строки будут зелёными, удалённые — красными.
