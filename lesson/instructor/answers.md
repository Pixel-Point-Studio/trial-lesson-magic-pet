# Эталонные ответы МОПа

Не открывать этот файл ученику до исчерпания лестницы подсказок. Тупик ограничивается тремя минутами.

## Study / Руни

- Дефект: обработчик `scenario:study` передаёт `Scenario.SPORT`.
- Исправление: заменить аргумент на `Scenario.STUDY`.
- Что ученик должен объяснить: условие распознаёт кнопку, аргумент определяет выбранный маршрут.
- Аварийная проверка: `./gradlew test --tests '*LessonRouteContractTest.studyRoute*'`.

## Sport / Игнис

- Дефект: условие сравнивает callback с `scenario:sports`.
- Исправление: заменить строку на `scenario:sport`.
- Что ученик должен объяснить: строковые идентификаторы должны совпадать точно; подпись кнопки от callback не зависит.
- Аварийная проверка: `./gradlew test --tests '*LessonRouteContractTest.sportRoute*'`.

## Blog / Скриба

- Дефект: обработчик удаления вызывает `completeTask(...)`.
- Исправление: вызвать `deleteTask(user, deletedTaskId)`.
- Что ученик должен объяснить: условие выбрало правильное событие, но вызван неверный метод с другим эффектом.
- Аварийная проверка: `./gradlew test --tests '*LessonRouteContractTest.blogRoute*'`.

## Единая лестница помощи

Наблюдение → файл → блок → сравнение значений → 3–5 строк → точный ответ. После каждой подсказки вернуть управление ученику. Не исправлять код за него.

## Финальная проверка

Повторить исходные шаги, выполнить две задачи, увидеть 100 XP и уровень 2, открыть `git diff`, попросить ученика объяснить исправленную строку и сделать commit.
