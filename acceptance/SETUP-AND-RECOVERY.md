# Сетап, токены и восстановление

## Перед уроком

1. Убедиться, что `main` чистый и актуальный.
2. Выполнить `./scripts/final-acceptance.sh` после изменения эталона.
3. Подготовить окружение:

   ```bash
   ./scripts/prepare-lesson.sh "Имя Фамилия" study
   ```

4. Открыть выведенный `LESSON_PATH` в IntelliJ.
5. Вставить уникальный токен в `.env`, запустить и проверить `/start`.

Один токен нельзя одновременно использовать в двух long-polling приложениях.

## Аварийный fallback

- AI не отвечает: очистить `LLM_API_URL` и перезапустить; локальные планы включатся автоматически.
- Личный Telegram/BotFather недоступен: выдать отдельный свободный школьный бот и заменить одну строку `TELEGRAM_BOT_TOKEN`.
- Ассет повреждён: удалить конкретный scenario-файл; бот использует `assets/common/fallback.png` или текст.
- Учебный код сломан: выполнить `git diff`, сохранить изменения ученика отдельно и вернуть только исправляемый файл командой МОПа из эталонного ответа.
- SQLite повреждена до урока: остановить приложение, переместить `data` в архив и создать пустой `data`. Во время урока базу не удалять без согласия ученика.

## После урока

1. Остановить Java-приложение.
2. Отозвать личный временный токен или ротировать школьный.
3. Убедиться, что `.env` не добавлен в Git.
4. Удалить worktree из исходного репозитория:

   ```bash
   git worktree remove /точный/LESSON_PATH
   git branch -D lesson/имя-дата
   ```

Перед удалением перепроверить точные путь и ветку. Удаление worktree стирает локальные `.env`, SQLite и незакоммиченные изменения внутри него; при необходимости сначала сохранить учебный diff.
