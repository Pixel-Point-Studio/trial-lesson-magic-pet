# Общие задания

## 0. Войти в проект

Открыть README, найти назначение и запуск, выполнить git status, создать ветку lesson/имя-фамилия.

Готово: лид видит свою ветку и объясняет её смысл.

- Ответ для МОПа
    
    git status → git branch --show-current → git switch -c lesson/имя-фамилия. Не выполнять git init.
    

## 1. Настроить и запустить

Создать .env, вставить токен, выполнить ./gradlew run, отправить /start.

Подсказки: пример рядом с README; имя файла ровно .env.

- Ответ для МОПа
    
    cp .env.example .env. В .env заменить только TELEGRAM_BOT_TOKEN. Через пять минут перейти на резервный токен.

# A. Руни / Учёба

## STUDY-01. Выбирается спортивный Pet

Шаги: /start → Учёба → имя → цель.

Ожидается Scenario.STUDY, Руни и учебный план. Получается SPORT и Игнис.

Задача: breakpoint в StudentBot, подтвердить причину, исправить одну строку.

Подсказки:

1. Ввод приходит в receiveMessage.
2. Остановись внутри scenario:study.
3. Сравни ID и значение в chooseScenario.
4. Должен передаваться Scenario.STUDY.
- Ответ STUDY-01
    
    Подготовленный баг вызывает chooseScenario(user, Scenario.SPORT) внутри условия scenario:study. Заменить SPORT на STUDY. Breakpoint должен показать buttonId равный scenario:study.
    

## STUDY-02. Персонализация

Переименовать кнопку, изменить первое fallback-задание или правило prompt.

- Ответ STUDY-02
    
    Кнопка: ui-texts.ru.json → buttons.scenarioStudy. Гарантированный результат: FallbackPlanGenerator → case STUDY. Prompt влияет только при работающем AI.
    

# B. Игнис / Спорт

## SPORT-01. Кнопка не работает

Ожидается запрос имени Игниса; фактически перехода нет.

Подсказки:

1. Текст и внутренний ID различаются.
2. Посмотри buttonId.
3. Сравни scenario:sport со строкой в buttonPressed.
- Ответ SPORT-01
    
    Подготовленный баг проверяет scenario:sports с лишней s. Исправить на scenario:sport. Scenario.SPORT оставить без изменения.
    

## SPORT-02. Безопасное задание

Изменить второе fallback-задание: 1–3 минуты, без боли, рекордов, диет и медицинских советов.

- Возможный ответ SPORT-02
    
    «Разбуди Игниса» — «Встань, расправь плечи и спокойно пройдись одну минуту в комфортном темпе». Единственного текста нет; важны безопасность и конкретность.
    

# C. Скриба / Блог

## BLOG-01. «Удалить» начисляет XP

Создать задачу → открыть → удалить. Ожидается исчезновение без XP; фактически задача выполняется.

Подсказки:

1. Callback распознан, ищи код после deletedTaskId.
2. Сравни completeTask и deleteTask.
3. Для удаления deliveryId не нужен.
- Ответ BLOG-01
    
    Подготовленный баг вызывает pet.completeTask(user, deletedTaskId, message.deliveryId()). Заменить на pet.deleteTask(user, deletedTaskId). Проверить: XP не меняется, задачи нет в обоих списках.
    

## BLOG-02. Голос Скрибы

Изменить сообщение удаления, prompt заголовков или первое fallback-задание.

- Возможный ответ BLOG-02
    
    В ui-texts.ru.json изменить taskDeleted на «Скриба растворила лишнюю запись в чернилах ✨». Это гарантированно видно без AI.
    

# Опционально: третий уровень

Только для быстрого лида или следующего спринта. Найти LevelProgression, assets выбранного пути и выбор изображения.

Текущий проект уже поддерживает уровень 3 от 250 XP и все ассеты. Для учебной задачи нужен отдельный дефект или исследование; не выдавать как незавершённую функцию.

- Текущий ответ
    
    levelFor возвращает 3 при experience от 250, 2 при 100–249 и 1 иначе. Для обязательного вау достаточно уровня 2 после двух задач.
